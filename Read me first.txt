Miller Driver Updater
=====================
Keeps this PC's drivers and apps up to date, from official sources only: Windows Update, nvidia.com and winget.
Free and open source (MIT License): https://github.com/mwmiller99-dot/MillerDriverUpdater

What it does
  Checks for driver updates (Windows Update), the newest NVIDIA GeForce driver (from nvidia.com, no NVIDIA
  account needed) and app updates (winget). You choose what to install. Before a driver changes, it creates a
  restore point and a backup, and it never restarts your PC on its own.

Installing
  1. Run MillerDriverUpdater-<version>-Setup.exe. It installs for your user account only, so no administrator
     password is needed. (MillerDriverUpdater.exe also runs on its own, without installing.)
  2. When the app opens, Windows asks whether to let it make changes: installing drivers requires administrator
     rights. Checking for updates changes nothing; only Install does.

  The installer is not code-signed yet, so Windows SmartScreen ("Windows protected your PC") or an antivirus may
  warn about it. Every release on GitHub lists the file's SHA-256 checksum and a GitHub build attestation, so you
  can confirm you have the official build (see SECURITY.md on GitHub). If an antivirus removes the app during
  setup, Setup pauses, explains how to allow it, and continues when you click Retry.

Using it
  - The check takes under a minute; nothing changes while it runs.
  - Drivers start ticked; apps start unticked. Click a row to tick it, or use Check all. Then click Install.
  - Apps that update themselves (Steam, Discord, browsers...) are listed last with an Open button. Open them and
    they update on their own; this app never runs them.
  - Each row shows its own progress; the bar at the top is the whole job.
  - If it says "Restart to finish", restart when it suits you. Nothing restarts on its own.
  - "Before you start" lists anything likely to get in the way (battery, low disk space, Windows Update service
    turned off...) with a button that fixes it.
  - "Needs attention" lists devices Windows reports a problem with, and says when an update on screen fixes one.
  - Hide (on any row) stops an update from being offered; Unhide brings it back.

If something goes wrong
  - Report a Problem (bottom of the window) saves the app's logs to a zip on your desktop and opens GitHub, where
    you can describe the problem. The zip lists device names and driver versions (no personal files), so share
    it only with someone helping you, not on a public page.
  - Roll Back appears next to any driver this app replaced; it puts the previous one back.
  - To uninstall: Settings > Apps > Installed apps > Miller Driver Updater > Uninstall.
